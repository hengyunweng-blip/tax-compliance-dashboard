## 1. A 修补丁：到期边界

规则现在是：原始发放所得年度为 `Y`、原始期限为 `N` 时，实际还款年度为 `Y+1` 至 `Y+N`；从 `Y+N+1` 才是 `expired`。

独立边界数据库的完整表格见 [sql-output.md](./sql-output.md#5-a-修补丁边界与连续性)。关键结果如下：

- `FY2023–24`：`active`，剩余年限 1，最低还款 `1,747,034` 分；
- `FY2024–25`：`expired`；
- 每年恰好按最低额还款时，最后一个还款年度期末余额为 `0`；
- 进入 `expired` 时若仍有余额，保留 `unresolvedBalanceCents`、显示未清偿金额和人工核对警告，且不自动写入分红记录。

此前遗漏的 `FY2021–22`、`FY2022–23` 已补入连续表，分别为期初 `4,730,989` / `3,234,697` 分，最低还款均为 `1,747,034` 分。

## 5. C3–C4：lodgment day、协议义务与条件核对

- `lodgment_day = min(公司税表用户录入的实际 lodged 日期, 公司税表 effective_due)`；没有实际日期时使用 `effective_due`，不默认当天。
- `scope_key` 已纳入唯一约束；每笔贷款使用 `loan:<loanId>`，公司两笔贷款不会互相覆盖。
- 协议义务单独进入看板、Inbox 与 `.ics`；提醒为 T-30/T-10/T-3/当天及逾期每日。
- 协议核对要求书面协议日期、文件、条款状态、利率、担保类型和期限均可追溯；只上传文件不会自动判定合规。
- `security_type = unknown` 直接 `blocked`，不默认七年期。
- 协议状态和缺失字段均在 API notes 中可追溯；实际 API/ICS 摘录见 [api-output.md](./api-output.md)。

## 6. C5：发放年、缺口与到期

- 发放所得年度显示“无最低还款要求（发放年度）”，不会产生缺口。
- 实际还款低于最低还款时显示差额与“可能产生视同股息后果”的警告；系统不自动创建分红记录。
- 还款期满后若余额不为零，显示“已到期”、未清偿余额和人工核对提示，不静默结束。

官方基准测试保持独立于实现结果：`tests/unit/div7a.test.ts` 从 `tests/fixtures/div7a/ato-baseline.json` 读取期望值 `1,747,034` 分。fixture 的来源是 ATO Division 7A calculator（[官方工具](https://www.ato.gov.au/calculators-and-tools/division-7a-calculator-and-decision-tool?page=1)），取数日期为 27 Aug 2026；测试注释明确说明该值不是测试套件自行计算的期望值。

## 9. 自审

### 9.1 反证法

| 结论 | 如果结论是错的，应观察到什么 | 实际观察 |
|---|---|---|
| 缺年度利率不会回退 | FY2027–28 会出现沿用 FY2026–27 的利息/最低还款数字 | 缺利率 API 返回金额 `null` 与“基准利率未配置”，没有金额 |
| 期初余额被使用 | FY2026–27 期初会错误显示本金 `10,000,000` 分或零 | UI、API、SQL 均为期初 `5,000,000` 分 |
| 到期边界正确 | FY2023–24 会提前 `expired` 或最低还款为 0 | 边界脚本显示 FY2023–24 active、最低还款 `1,747,034` 分；FY2024–25 才 expired |
| 协议按贷款独立 | 两笔贷款会共用/覆盖同一个 obligation 或 ICS event | SQL/API 使用不同 `loan:<id>`，Inbox/ICS 各有独立贷款标识 |
| 缺口不自动变分红 | 还款不足后会多出 dividend 记录 | 测试和 expired warning 均只显示警告，未创建分红记录 |

### 9.3 主动暴露的三处最没把握点及针对性验证

1. **旧贷款的期初余额与剩余年限接续**：最容易把切换日误当作重新起算日。用 FY2019–20、7 年期、30 Jun 2026 期初余额的 SQL/API/UI 三处交叉，确认剩余年限由原始发放年度推导而不是从切换点重置。
2. **税表实际提交日对协议截止日的刷新**：容易忘记只接受用户录入日期或把协议误套通用顺延。单元测试先无 lodged 日期、再录入更早日期；同时检查独立 `scope_key` 和 `.ics` 日期。
3. **期满但仍有余额的状态**：容易把 expired 当作安全结束。用无还款贷款测试期满后的余额、warning 和无 dividend 记录，并用缺利率截图确认“无法判断”不会变成 0。

### 9.4 未能验证项

本章节刻意非空：

- ATO 规则、基准利率和官方计算器页面可能在 2026-08-29 之后变化；本报告只证明取数日的来源与程序行为，不证明未来年度政策不变。
- 本次没有向 ATO 或 ASIC 发起真实申报/付款，也没有验证政府网站最终接受状态；系统按范围不提供自动申报。
- 期初余额使用的是 Gate 6 临时演练说明，不是用户会计 FY2025–26 底稿原件；真实接管前仍需用户核对并重新录入来源。
- Browser 验证的是本地窄屏/桌面页面，不验证真实手机相机权限、拍照上传或移动网络行为。
- 协议文件只验证了文件 ID/字段的存在和条件门控，未对真实贷款协议的法律内容作独立法律意见。
